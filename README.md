# Exim data extractor and sorter
## Prerequsitions:
    exim mail server running on debian
    dovecot
## Usage
    run to sort your emails, the script will create an output to mailbox_data.csv that can be easily
    imported in excel.
    The data conzists of mailbox size, DNS provider checkup if you or your org is an owner of the domain,
    last login if the user is active on this domain and in witch box.
    ### Show loading 
        fuction show loading is primary used to show loading bar when waiting for the extraction and  file generation.
    
## Dependencies
    This is 100% bash script running only native bash.
